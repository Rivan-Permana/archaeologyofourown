## Implementation Notes

- Session opt-out confirmed: `session: false` in `astro.config.mjs`; `dist/server/wrangler.json` has no `kv_namespaces` and no `images` binding.
- CSP hashing verified with Astro 7.4.12: `security.csp` writes a `<meta http-equiv>` policy with script hashes into each prerendered page. `public/_headers` carries only what a meta policy cannot (`frame-ancestors`, `object-src`, `base-uri`) plus HSTS, nosniff, Referrer-Policy, `X-Robots-Tag`. Both policies apply (intersection), so `_headers` must never add `script-src`. Style policy keeps `'unsafe-inline'` as the AD requires, but Astro also emits no style hashes here, so it is effective.
- Astro adds no on-demand output without a server route, so `src/pages/{admin,api,media}/[...x].ts` return a JSON 404 as a deny-by-default backstop; this also makes the Worker bundle and middleware build. Verified with `wrangler dev`: `/admin/x` and `/api/build/snapshot` return 503 `unauthorized` (no auth config, fail closed), unknown `/api/*` and `/media/*` return 404, static pages carry all headers.
- `X-Robots-Tag: noindex` is static in `_headers`; Story 1.13 must make it depend on `PUBLIC_LAUNCH` (robots.txt and the meta tag already do).
- Tests use `node --test` with native type stripping (no new dependency). `npm run check` runs `wrangler types` first; `worker-configuration.d.ts` is generated and git-ignored.
- Review layers (blind, edge-case, gap subagents) were skipped on user's instruction to run one cheap lane; Story 1.1 is not in the Opus-review list. Self-review of the diff only.
- Not done (user-gated): GitHub repo, Workers Builds connection, `wrangler login`, workers.dev subdomain, first deploy. `npm audit` reports 14 high advisories (picomatch ReDoS via Astro/Vite build tooling); the suggested fixes downgrade to Astro 5, so versions stay pinned per the Stack table.
